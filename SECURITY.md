# Security Policy / Politique de sécurité

- [English](#english)
- [Français](#français)

## English

### Supported versions

Only the latest release receives security fixes.

### Reporting a vulnerability

Please don't open a public issue. Report the problem privately through [GitHub's vulnerability reporting form](https://github.com/SacBruine237275/messages-control/security/advisories/new).

Include:

- the mod, NeoForge and Minecraft versions
- the steps to reproduce the problem
- what an attacker could do with it

This is a project maintained in my spare time, so I can't promise a response time. I will reply as soon as I can and credit you in the fix if you wish.

## Français

### Versions prises en charge

Seule la dernière version publiée reçoit des correctifs de sécurité.

### Signaler une vulnérabilité

Merci de ne pas ouvrir d'issue publique. Signale le problème en privé avec le [formulaire de signalement de vulnérabilité de GitHub](https://github.com/SacBruine237275/messages-control/security/advisories/new).

Indique :

- les versions du mod, de NeoForge et de Minecraft
- les étapes pour reproduire le problème
- ce qu'un attaquant pourrait en faire

Ce projet est maintenu sur mon temps libre, je ne peux donc pas garantir de délai de réponse. Je répondrai dès que possible et je te créditerai dans le correctif si tu le souhaites.
